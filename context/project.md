# FlashMaster

## Project Overview

FlashMaster is a modern flashcard learning platform built with Next.js, TypeScript and TailwindCSS.

The goal of the project is to provide an effective learning experience using active recall and spaced repetition techniques.

The application allows users to create, organize, study and track flashcards across multiple subjects.

---

## Business Goals

- Improve learning efficiency
- Reduce forgetting rate
- Provide enjoyable study experience
- Support long-term retention
- Enable progress tracking

---
